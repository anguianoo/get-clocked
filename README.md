# get-clocked
firefox extension to display clock

# How to add it to Firefox (quick test install)
1. Download clock-bar.zip and unzip it into a folder.
2. In Firefox, type about:debugging#/runtime/this-firefox in the address bar and press Enter.
3. Click Load Temporary Add-on….
4. Go into the unzipped folder and select manifest.json.
5 .Open or refresh any website and the clock appears at the top. Click the clock icon in the toolbar to customize it. If the icon isn't visible, click the puzzle-piece Extensions button and pin it.
